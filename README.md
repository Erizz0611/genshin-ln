# Genshin Impact — Light Novel tiếng Việt

Web đọc light novel chuyển thể (phi thương mại) cốt truyện Genshin Impact. Lời thoại theo bản tiếng Việt chính thức của game.

Đọc tại: https://erizz0611.github.io/genshin-ln/

## Thêm màn mới
1. Viết file nguồn `_source/manX.txt` (định dạng `#CH|nhãn|tên chương|ảnh|nhiệm vụ`, `>` nhật ký nhiệm vụ, `---` ngắt cảnh).
2. Thêm 1 mục vào `ACTS` trong `_source/acts.py`, cập nhật hồ sơ trong `_source/characters.py`.
3. Chạy `cd _source && python web_build.py ..` rồi commit + push.
